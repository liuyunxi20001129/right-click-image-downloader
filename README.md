# 快速下载原图

一个 Tampermonkey / 油猴（Violentmonkey）用户脚本。右键点网页任意图片，脚本会**自己判断哪个才是原图**——缩略图会自动进详情页找原图，多个候选按文件大小判定——然后**静默下载最高清版本**，并以**网页上显示的名称**命名，不再是一串 UUID 乱码。下载经 blob 落盘并按文件头识别真实格式，**本地文件名与提示完全一致**。

## ✨ 功能

- **右键即下载**：鼠标右键点击网页图片，自动静默下载原图，不弹菜单干扰。
- **真·原图判定**：
  - 缩略图外层链接指向详情页时，自动**进详情页**抓 `og:image` / 主图 `data-original` / `srcset` 最大图；
  - 内置常见缩略图变换规则：WordPress `-300x200`、微博 `orj360→oslarge`、Twitter/X `name=orig`、Pinterest `/236x/→/originals/`、B 站 `@320w` 后缀；
  - 多个候选地址 **HEAD 探测比对字节数，最大者判定为原图**；下载失败自动换下一个候选。
- **按网页命名**：优先使用网页上显示的图片名称（链接 title / figcaption / alt / 详情页标题等），随机串名称自动回退到页面标题；扩展名按**文件头魔数**确定（XHR 抓 blob 落盘，绕开 CDN 的 webp 协商与浏览器按 Content-Type 改名的行为），PNG 不会再被存成 `.jpg`，提示的文件名即本地文件名。
- **花瓣网深度适配**：调官方 `v3/pins` 接口拿**签名原图**（`file.url` / `bucket+key` 裸地址，实测为原始文件）、真实格式与宽高，用「上传者发布的内容」(`raw_text`) 命名；修复相关推荐图张冠李戴的 pin 识别问题（优先右键图自己的链接）；兼容全部现行图床域名（`hbimg.huaban.com` / `gd-hbimg.huaban.com` / `gd-hbimg-edge.huaban.com` / `hbimg.huabanimg.com`）。
- **不误伤**：按住 **Shift** 右键 → 恢复浏览器原生菜单；按住 **Alt** 右键 → 调试模式（列出候选原图、接口返回与候选名称，不下载）。

## 📦 安装

- **GreasyFork（推荐，装完自动更新）**：在 GreasyFork 搜索「快速下载原图」并安装，或访问脚本页一键安装。
- **手动安装**：打开篡改猴管理面板 → 「添加新脚本」→ 把本仓库 `right-click-image-downloader.user.js` 全文粘贴进去 → 保存。
- ⚠️ **v2.1 起脚本更名为「快速下载原图」**：篡改猴会把它当成一个新脚本，请手动删除旧版「右键原图静默下载」，避免两个脚本同时生效。

## 🛠 使用

1. 浏览任意网页，找到想保存的图片。
2. **右键图片（含缩略图卡片外层）** = 找原图并静默下载（按网页名称命名）。
3. **Shift + 右键图片** = 恢复浏览器原生右键菜单。
4. **Alt + 右键图片** = 调试模式：查看候选原图地址、花瓣接口返回与候选文件名。

## 🔄 更新

- 通过 GreasyFork 安装的，平台会自动推送更新。
- 手动安装的，重新粘贴最新版 `.user.js` 即可。

## 🌐 支持的站点

- 专门优化：**花瓣网**（官方接口取签名原图与发布内容命名）。

## ❓ 常见问题

- **下载不成功 / 右键没反应？** 确认已更新到 v2.2+。v2.2 起下载走 `GM_xmlhttpRequest` 抓 blob，脚本头已声明 `@connect`（花瓣图床 + `self` + `*`）。如果篡改猴曾弹出「跨域请求」授权窗而你点了**拒绝**，请求会被一直拦截——到篡改猴该脚本的「设置 → 域名」里删掉拒绝记录（或选「始终允许所有域」）即可。
- **下载的还是小图？** 用 Alt+右键 看调试信息，把候选地址贴到 [Issues](https://github.com/liuyunxi20001129/right-click-image-downloader/issues) 反馈。
- **本地文件名和提示不一样？** v2.1 起改为 blob 落盘 + 文件头识别格式，两边必然一致；唯一例外是下载目录里已有同名文件时，浏览器会自动加 `(1)` 后缀（所有下载都一样）。
- **想恢复原生右键菜单？** 按住 Shift 再右键即可。
