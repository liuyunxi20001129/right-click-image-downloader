# 右键原图静默下载（按网页命名）

一个 Tampermonkey / 油猴（Violentmonkey）用户脚本。右键点网页任意图片，自动**静默下载最高清原图**，并以**网页上显示的名称**命名——不再是一串 UUID 乱码。

## ✨ 功能

- **右键即下载**：鼠标右键点击网页图片，自动静默下载原图（最高清版本），不弹菜单干扰。
- **按网页命名**：优先使用网页上显示的图片名称（alt / title / 图说 / 画板名 / 页面标题等），避免下载出 `469490d2-...` 这类随机文件名。
- **识别原图**：自动取 `srcset` 中最大的一张；兼容 `data-original` 等懒加载属性；对**花瓣网**走官方接口取「上传者发布的内容」命名。
- **不误伤**：按住 **Shift** 右键 → 恢复浏览器原生菜单；按住 **Alt** 右键 → 调试模式（列出抓到的候选名称与原图地址，不下载）。

## 📦 安装

- **GreasyFork（推荐，装完自动更新）**：在 GreasyFork 搜索「右键原图静默下载」并安装，或访问脚本页一键安装。
- **手动安装**：打开篡改猴管理面板 → 「添加新脚本」→ 把本仓库 `right-click-image-downloader.user.js` 全文粘贴进去 → 保存。

## 🛠 使用

1. 浏览任意网页，找到想保存的图片。
2. **右键图片** = 静默下载原图（按网页名称命名）。
3. **Shift + 右键图片** = 恢复浏览器原生右键菜单。
4. **Alt + 右键图片** = 调试模式：查看脚本抓到的候选文件名与原图地址。

## 🔄 更新

- 通过 GreasyFork 安装的，平台会自动推送更新。
- 手动安装的，重新粘贴最新版 `.user.js` 即可。

## 🌐 支持的站点

- 通用：任意网站都可用（自动按网页名称 / 页面标题命名）。
- 专门优化：**花瓣网**（取上传者发布内容命名；无发布内容时回退画板名）。

## ❓ 常见问题

- **下载的文件名还是乱码？** 说明你浏览器里跑的是旧脚本。请在篡改猴里删除旧脚本，重新安装本仓库最新版（v1.3+）。
- **想恢复原生右键菜单？** 按住 Shift 再右键即可。
