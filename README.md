# 快速下载原图

一个 Tampermonkey / 油猴（Violentmonkey）用户脚本。**Alt + 左键**点网页任意图片（含缩略图卡片外层），自动找原图并下载最高清版本，按网页上显示的名称命名；文件头识别真实格式，**本地文件名与提示完全一致**。右键为浏览器原生菜单，脚本不拦截。

## ✨ 功能

- **Alt + 左键即下载**：按住 Alt 再左键点图片 = 找原图并下载（按网页名称命名）。普通右键 = 浏览器原生菜单，不被脚本拦截。
- **真·原图判定**：
  - **花瓣网**：调官方 `v3/pins` 接口拿**签名原图**（`file.url` / `bucket+key` 裸地址）+ 发布内容(`raw_text`)命名；兼容全部现行图床域名（`hbimg.huaban.com` / `gd-hbimg.huaban.com` / `gd-hbimg-edge.huaban.com` / `hbimg.huabanimg.com`）。
  - **通用站**：内置缩略图变换规则（WordPress `-300x200`、微博 `orj360→oslarge`、Twitter `name=orig`、Pinterest `/236x/→/originals/`、B 站 `@后缀`）；外层链接指向详情页时自动进详情页抓 `og:image` / 主图 `data-original` / `srcset` 最大图。
  - 多个候选原图 **并发竞速**，最快者先落盘（典型 <1 秒）。
- **按网页命名**：优先用网页上显示的图片名称（包裹 `<a>` 的 title/aria-label > figcaption > alt/title/data-* > 相邻短文本 > 详情页标题 > URL 文件名），随机串自动回退；扩展名按**文件头魔数**确定（绕开 CDN 的 webp 协商与浏览器按 Content-Type 改名），提示的文件名即本地文件名。
- **双通道下载**：每候选走【页面 fetch + GM_xhr】双通道，fetch 命中浏览器缓存/CDN 最快，GM_xhr 兜底跨域；含 stall 与整体超时检测，慢图不会被误杀。
- **不误伤**：普通右键完全交给浏览器原生菜单。

## 📦 安装

- **GreasyFork（推荐，自动更新）**：在 GreasyFork 搜索「快速下载原图」并安装。
- **手动安装**：打开篡改猴管理面板 → 「添加新脚本」→ 把本仓库 `right-click-image-downloader.user.js` 全文粘贴进去 → 保存。
- 因脚本 `@id` 保持不变，安装 v3.x 会**自动覆盖**旧版（无需手动删除）。

## 🛠 使用

1. 浏览任意网页，找到想保存的图片。
2. **Alt + 左键图片（含缩略图卡片外层）** = 下载原图（按网页名称命名）。
3. **普通右键** = 浏览器原生菜单（脚本不拦截）。
4. 脚本菜单里有「使用说明」可随时查看调试信息。

## 🌐 支持的站点

- 通用：任意网站（详情页抓取 + 规则变换 + 竞速下载）。
- 专门优化：**花瓣网**（官方接口取签名原图与发布内容命名）。

## ❓ 常见问题

- **下载不成功 / 没反应？** 确认已安装 v3.x。脚本用到 `GM_xmlhttpRequest` 跨域，需 `@connect`（已声明）。若篡改猴曾弹「跨域请求」授权窗而点了**拒绝**，请求会被一直拦截——到该脚本「设置 → 域名」删掉拒绝记录（或选「始终允许所有域」）。
- **下载的还是小图？** 看下载提示里的候选信息，或到脚本菜单「使用说明」排查候选地址，把问题反馈到 Issues。
- **本地文件名和提示不一样？** v3.x 改 blob 落盘 + 文件头识别格式，两边必然一致；唯一例外是下载目录已有同名文件时浏览器自动加 `(1)`。
- **想恢复原生右键菜单？** 直接右键即可（脚本 v3 起不再拦截右键）。
